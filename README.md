# รายงานการทำงานประจำวัน (Daily Construction Report)

เว็บแอพกรอกแบบฟอร์ม **รายงานการทำงานประจำวัน** โครงการงานซ่อมแซมอาคารพระคลังข้างที่ฯ
จัดหน้าตามแบบฟอร์ม Word ต้นฉบับ และส่งออกเป็น **PDF** หรือ **Word (.docx)** ได้

## ใช้งาน

เปิดหน้าเว็บ แล้วกรอกข้อมูลได้เลย ไม่ต้องติดตั้งหรือสมัครสมาชิก ใช้ได้ทั้งคอมพิวเตอร์ มือถือ และไอแพด

- **มุมมองกรอกข้อมูล:** ฟอร์มช่องใหญ่ เหมาะกับมือถือ (เปิดเป็นค่าเริ่มต้นบนจอเล็ก)
- **มุมมองหน้ากระดาษ:** กรอกบนหน้า A4 ตามแบบฟอร์มจริง เหมาะกับคอมพิวเตอร์และไอแพด
- สลับมุมมองได้ตลอด ข้อมูลเป็นชุดเดียวกัน
- บนมือถือ แตะช่องรูปเพื่อถ่ายภาพจากกล้องได้ทันที และเซ็นชื่อด้วยนิ้วได้
- เพิ่มไว้ที่หน้าจอโฮม: Safari กด แชร์ → เพิ่มไปยังหน้าจอโฮม / Chrome กด ⋮ → เพิ่มลงในหน้าจอหลัก

- **หน้า 1 รายงานประจำวัน:** อากาศ, การระงับงาน, เวลาทำงาน, รายการงาน, กำลังคน, เครื่องจักร, ปัญหาและแนวทางแก้ไข, ลายเซ็น, สำเนา
- **เอกสารแนบ:** ตารางรายการงาน 24 แถวต่อหน้า เพิ่มหน้าได้ไม่จำกัด
- **ภาพถ่ายการทำงาน:** 6 รูปต่อหน้า พร้อมคำบรรยาย เพิ่มหน้าได้ไม่จำกัด
- **ลายเซ็น:** วาดด้วยเมาส์ นิ้ว หรือปากกา
- **คำนวณอัตโนมัติ:** รวมกำลังคน, รวมเวลาทำงาน, จำนวนเอกสารแนบ, เลขหน้า
- **ส่งออก:** PDF และ Word (.docx ใช้ฟอนต์ Angsana New ตามต้นฉบับ)
- **บันทึก / เปิดไฟล์ข้อมูล (.json):** เก็บรายงานแต่ละวัน หรือคัดลอกรายงานเมื่อวานมาแก้ต่อ

## ข้อมูลเก็บที่ไหน

ข้อมูลทั้งหมดอยู่ในเบราว์เซอร์ของผู้ใช้แต่ละคนเท่านั้น (localStorage) ไม่มีการส่งขึ้นเซิร์ฟเวอร์
ร่างจะหายถ้าล้างข้อมูลเบราว์เซอร์ หรือเปลี่ยนเครื่อง จึงควรกด **บันทึกไฟล์ข้อมูล** เก็บไว้ทุกวัน

## หมายเหตุ

- บนเว็บและ PDF ใช้ฟอนต์ Sarabun (Google Fonts)
- ไฟล์ Word ควรเปิดบนเครื่องที่มีฟอนต์ Angsana New (Windows) เพื่อให้ระยะตรงตามต้นฉบับ
- เป็นไฟล์ HTML ไฟล์เดียว โหลดไลบรารีจาก CDN: html2canvas, jsPDF, docx
